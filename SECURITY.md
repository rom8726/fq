# Security Policy

## Supported Versions

fq is still pre-1.0. Security fixes are prepared for the current development branch
and the latest released minor line when practical.

| Version | Supported |
|---|---|
| `main` | yes |
| latest minor release | best effort |
| older releases | no |

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository when it is available.
If it is not available, contact the maintainer privately through the repository owner
profile and include enough detail to reproduce the issue.

Helpful reports include:

- affected version or commit;
- deployment mode and relevant configuration;
- steps to reproduce;
- expected and observed impact;
- whether the issue is already public or actively exploited.

The maintainer will acknowledge valid reports as soon as possible, coordinate a fix,
and publish release notes once disclosure is safe.
